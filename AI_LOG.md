# AI_LOG

## Чем пользовался

- Claude (Opus 5.5) в claude.ai — сделал первую версию проекта.
- Claude Code (Opus 5.5) в десктоп-приложении — ревью, исправления, бонусы, CI.
- Правила для ассистента записал в `CLAUDE.md`: деньги только `int` в копейках, переходы статусов
  только через `ALLOWED_TRANSITIONS`, на каждое изменение логики — тест.

## Как ставил задачу

1. Сначала скинул PDF и попросил не писать код, а найти места, где легко ошибиться.
   Получился список: копейки в графике, повторные запросы, подпись вебхука. По нему потом
   проверял тесты.
2. Потом попросил собрать проект по заданию и бонусам, с условием держать расчёты
   (`pricing.py`) отдельно от базы, чтобы их можно было тестировать без сервера.
3. Во второй сессии отдал готовый репозиторий на ревью и попросил не верить зелёным тестам,
   а попробовать сломать API странными входными данными.

## Где модель ошиблась

- `created_at` отдавался без часового пояса — SQLite его теряет. Тесты этого не ловили,
  заметили только на живом запросе. Исправили, добавили проверку в тест.
- Пустой `Idempotency-Key` записывался в базу, и повторный запрос падал с 500.
  Огромный `tariff_id` тоже давал 500, а `"tariff_id": true` молча создавал платёж за тариф 1.
  При 78 зелёных тестах — нашлось только на ревью. Теперь везде 422/404 и тесты на каждый случай.
- В `services.py` модель импортировала FastAPI, хотя в `CLAUDE.md` сама записала, что так нельзя.

## Как проверял

- `pytest` (105 тестов) и `ruff`, плюс то же самое в GitHub Actions на каждый push.
- Руками прошёл все сценарии в Swagger: промокод маленькими буквами, график рассрочки,
  повтор ключа, запрещённый переход — и проверял, что статус после 409 не поменялся.
- Подпись вебхука проверил через curl: без подписи и с левой — 401, с правильной — 200.
- Запустил через `docker compose up`. Сначала запросы не доходили до контейнера — оказалось,
  на том же порту 8000 висел старый `uvicorn`. Понял по логам: в контейнере были только
  healthcheck'и.
